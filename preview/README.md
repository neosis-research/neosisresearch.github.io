# View the website before deployment

This branch contains the website source and a portable preview. GitHub Pages does not need to be enabled.

## View the preview

Download `neosis-research-private-preview.zip` from this folder using GitHub's **Download raw file** button. Extract the entire ZIP, then open the extracted `index.html` in your browser. Keep its folders together so navigation, styles, fonts, and images can load. No Node installation is required for this preview.

The inquiry worksheet prepares text locally and does not send anything. Clipboard availability depends on your browser; the download option is also available.

`homepage.png` shows the complete homepage. GitHub can display it directly.

## Develop locally

See the repository's main README for `npm ci` and `npm run dev` instructions. The preview ZIP is a snapshot, not the editable source; regenerate it after website changes.

The repository is public, so these files are publicly downloadable. Opening the extracted preview runs it on your computer; it does not publish a hosted website.
